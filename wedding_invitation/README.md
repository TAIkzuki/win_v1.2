
# Свадебное приглашение — Flask

Простой сайт-приглашение с админ-панелью, персональными ссылками и подсчётом меню.

## Запуск Windows

Откройте терминал в папке проекта:

```powershell
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
py app.py
```

Откройте:
http://127.0.0.1:5000/

Админ-панель:
http://127.0.0.1:5000/admin

Пароль администратора по умолчанию:
`1234`

## Важно

Для реального сайта поменяйте пароль через переменную окружения:

```powershell
$env:ADMIN_PASSWORD="ваш_сложный_пароль"
py app.py
```

База `wedding.db` создаётся автоматически.

## Как пользоваться

1. Зайдите в `/admin`.
2. Нажмите «Добавить гостя».
3. Укажите имя и количество приглашённых.
4. Сайт создаст персональную ссылку.
5. Отправьте ссылку гостю.
6. Ответы появятся в админке.
7. В блоке «Итоги меню» видно, сколько нужно мяса, рыбы и птицы.

Для доступа гостей из интернета нужен хостинг/сервер и домен. Локальная ссылка `127.0.0.1` работает только на вашем компьютере.
